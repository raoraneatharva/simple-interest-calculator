# Simple Interest Calculator

A simple Bash program that calculates simple interest using principal, annual interest rate, and time in years.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Requirements

- Bash
- awk (used for decimal calculation)

## Run the program

    bash simple-interest.sh

Enter the principal, annual rate, and time when prompted.

## Example

For principal 1000, rate 5%, and time 2 years, the simple interest is 100.00.
