# Contributing Guidelines

Thank you for considering contributing to the Simple Interest Calculator.

## How to Contribute

1. Fork the repository.
2. Create a branch for your change.
3. Make your changes and test them.
4. Commit your changes with a clear message.
5. Open a pull request explaining the change.

## Guidelines

- Keep Bash code readable and straightforward.
- Use meaningful variable names.
- Add comments when they improve clarity.
- Test the script with different input values.

## Reporting Issues

Use GitHub Issues to report bugs or suggest improvements. Include steps to reproduce the issue and the expected result.
